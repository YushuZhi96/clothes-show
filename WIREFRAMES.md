# iOS Wireframes

## Prototype Scope

The first clickable prototype is implemented as a static local iOS mockup:

- `index.html`
- `styles.css`
- `app.js`

The mockup uses an iPhone 17 Pro-style portrait frame and includes five tabs:

- Home
- Wardrobe
- Generate
- Outfits
- Profile

## Screen Notes

### Home

Purpose:

- Make the product feel playful and low-pressure.
- Give users a direct path into outfit generation.

Main elements:

- Product identity.
- Strong Memphis-style hero.
- Primary generation button.
- Clothing upload shortcut.
- Portrait upload shortcut.
- Recent wardrobe preview.

### Wardrobe

Purpose:

- Let users scan and manage clothing clearly.

Main elements:

- Search box.
- Category chips.
- Two-column clothing grid.
- Floating add button.

### Generate

Purpose:

- Guide users through the core AI generation flow.

Main elements:

- Portrait selector.
- Selected clothing items.
- Scene and style chips.
- Sticky generate button.

### Outfits

Purpose:

- Show generated and saved outfit references.

Main elements:

- Large result image.
- Outfit explanation.
- Regenerate and share buttons.
- Saved outfit previews.

### Profile

Purpose:

- Manage account, portraits, privacy, and generation quota.

Main elements:

- User profile card.
- Remaining generation count.
- Portrait profile entry.
- Privacy and data entry.
- Generation history entry.
- Delete portrait data action.
