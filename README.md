# Clothes Show

Clothes Show is an iOS-first wardrobe and AI outfit reference prototype.

The current version is a static frontend prototype focused on the wardrobe flow:

- iPhone Pro-style mobile mockup.
- Memphis-inspired visual direction.
- Clothing import flow.
- Image crop and white-background simulation.
- Wardrobe category filtering.
- Wardrobe search.
- Clothing detail page.
- Multi-tag editing.

## Run Locally

From the project root:

```bash
python3 -m http.server 5188
```

Then open:

```text
http://localhost:5188
```

## Current Status

This is not a production iOS app yet. It is a static prototype used to validate product flows, UI direction, and wardrobe management interactions before choosing a native iOS or cross-platform implementation stack.
